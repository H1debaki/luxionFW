# luxionFW

Luxion（陸上競技用のペーシングライト）の本体を更新するファイル（.lxn）の配布場所です。操作アプリは、ここにある `latest.json` を読んで新しいバージョンがあるかを確かめます。

## ファイル

| ファイル | 内容 |
|---|---|
| `latest.json` | 最新版の情報 |
| `luxion_<バージョン>_fw<NN>.lxn` | 更新ファイル。本体のプログラム、本体のファームウェア、心拍受信機のファームウェアが入っています |

## latest.json の項目

| 項目 | 内容 | 例 |
|---|---|---|
| `format` | この形式の番号 | `1` |
| `program` | 本体のプログラムのバージョン | `"2.08"` |
| `firmware` | 同梱した本体のファームウェアのバージョン | `36` |
| `receiver` | 同梱した心拍受信機のファームのバージョン | `"0.2.4"` |
| `file` | 更新ファイルの名前 | `"luxion_208_fw36.lxn"` |
| `size` | 更新ファイルの大きさ（バイト） | |
| `sha256` | 更新ファイルの SHA-256 | |
| `released` | 公開した日 | `"2026-10-25"` |
| `notes` | 変更の内容 | |

## 更新のしかた

### 操作アプリから

1. インターネットにつながる場所で、設定画面のいちばん下の「アップデート」にある「新しい版を確認」を押し、表示されたバージョンをダウンロードします。ダウンロードしたファイルはスマホに保存されます。
2. 本体に接続し、全チームを止めてから「本体を（バージョン）にアップデート」を押します。本体は再起動し、30秒ほどつながりません。新しいバージョンで起動できなかったときは、本体が前のバージョンに自動で戻ります。
3. ファームが変わるバージョンでは、続けて「ファームウェアを書き込む」を押します。本体がファームウェアの書き込み先を見つけられないときは、本体のブラウザ画面の SYSTEM OP にある手動の手順に従ってください。

### 本体のブラウザ画面から

このリポジトリから .lxn をダウンロードし、本体の画面の SYSTEM OP でアップロードします。

心拍受信機のファームはどちらの方法でも本体の SYSTEM OP から書き込みます。走行中の更新と、古いバージョンへの書き戻しは、本体が断ります。

## 署名

本体は v2.08 から、更新ファイルに付いた Ed25519 の署名を本体に入っている公開鍵で確かめ、正規の更新ファイルだけを適用します。署名に使う秘密鍵はこのリポジトリにはありません。

移行のため以前の方式の署名も付けているので、v2.07 以前の本体にも v2.08 の更新ファイルを適用できます。v2.08 にしたあとは、新しい方式の署名だけを確かめます。
